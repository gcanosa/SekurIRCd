security notes

No eval, system or shell-out in the request path; enforced line, parameter and nick limits; a per-client flood guard; per-connection isolation so one bad client cannot crash the daemon. Prefer scrypt password_hash over plain passwords, enable [tls], and restrict [server].bind for network-level isolation. make debug builds an ASan+UBSan binary.
