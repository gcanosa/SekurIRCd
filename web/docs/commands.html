commands & modes

Type /HELP for a summary and /HELP <command> for syntax on any command below.

user commands

CommandPurpose
NICK USER PASS CAP QUITRegistration and disconnect. CAP negotiates IRCv3 features.
JOIN PART NAMES TOPIC LISTChannels. LIST supports ELIST conditions (>n, <n, glob).
KICK INVITE KNOCKModeration and access. KNOCK asks ops for an invite to a +i/+k channel.
PRIVMSG NOTICEMessages. Prefix a channel with @, % or + (STATUSMSG) to reach only that rank or higher.
WHO WHOIS WHOWAS USERHOST ISONLookups. WHO supports WHOX: WHO <mask> %fields,token.
MONITOR WATCHOnline/offline watch lists. Prefer MONITOR (up to 100 entries).
AWAY SETNAME SILENCEAway status, change realname live, per-client private-message ignore masks.
MODEQuery or change channel and user modes.
VHOSTActivate a configured virtual host, or VHOST off.
REGISTER AUTHENTICATE CERTAccounts: create an account, SASL login, bind a TLS client certificate. Needs [accounts] enabled.
RULESShow the network rules from ircd.rules (plain text, lines under 78 characters).
MOTD ADMIN INFO VERSION TIME UPTIME LUSERS LINKS MAP STATS HELPServer information. STATS m and u are open to everyone.
SERVLIST SQUERYList and message services pseudo-users such as ChanServ.
GLOBNon-standard: glob-match nicknames server-wide (invisible users hidden unless you share a channel or you are an oper).
PING PONGKeepalive.

operator commands

All require /OPER with a configured [[operators]] login.

CommandPurpose
OPEROPER <name> <password>. Grants +o, and also +s and +w.
KILLDisconnect a user from the network.
KLINE GLINE ZLINE<mask> [duration] [:reason]. With no arguments, list active lines.
UNKLINE UNGLINE UNZLINERemove a line.
WALLOPSMessage every user with +w.
REHASHReload the config, MOTD, oper MOTD and rules live.
OPERMOTDShow oper.motd. It is also sent automatically when you /OPER up.
DIE RESTARTShut down, or re-exec in place. Can require an extra password.
CHGHOST SETHOSTForce-set another local user's displayed host, or your own (SETHOST off clears it).
SAJOIN SAPART SAMODEForce a user into or out of channels, or change channel modes, bypassing +i +k +l +b +z and op requirements. +r stays services-only.
CONNECT SQUITBring up or drop a configured server link.
TRACE STATSConnected clients and linked servers; STATS k/g/z/l/o list bans, links, operators.

channel modes

ModeMeaning
+n +tNo outside messages; only ops set the topic. Default for new channels (default_modes = "nt").
+iInvite only.
+mModerated.
+p +sPrivate / secret. Hides name, topic and membership from non-members.
+k +lKey, and user limit.
+zOnly clients connected over TLS may join.
+rRegistered with services. Set and cleared only by ChanServ.
+PPermanent: the channel survives going empty.
+C +T +SBlock CTCP, block channel NOTICE, strip color codes.
+N +Q +VBlock nick changes, block kicks, block invites.
+o +h +vPrefix modes: @ op, % halfop, + voice.
+b +e +IBan, ban exception, invite exception. Up to 100 entries each. Extban a:<account> matches by SASL account.

user modes

ModeMeaning
+iInvisible. Hidden from GLOB unless you share a channel or the searcher is an oper.
+wReceive WALLOPS.
+dDrop CTCP sent to you.
+sServer notices (opers): bans, connects, kills, failed OPER, links.
+oOperator. Granted by /OPER.
+ZConnected over TLS. Set by the server.
+rIdentified to an account. Set by the server.

[security] default_user_modes (e.g. "iw") applies self-togglable modes automatically after registration. +o, +Z and +r can never be granted this way.
