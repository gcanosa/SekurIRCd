wizard

Fill in the form and the wizard writes a complete sekurircd.toml. If you turn on services, it also writes services.toml for NickServ and ChanServ, with both files' link settings already matching. With the Protection bundle on, it writes protection.toml too. The files are built in your browser and nothing is sent anywhere. Any setting you leave out uses its built-in default, which configuration documents.

On the server itself, tools/makeconf.py (or sekurircd --makeconf) asks the same questions in the terminal. It also hashes passwords, runs both daemons' --check and can make a self-signed certificate. See install: create the config.
