configuration

Copy config/sekurircd.template.toml to a live file and point the daemon at it with --config. The template documents every key. REHASH (or --rehash) reloads it without dropping anyone.

Relative paths: motd, tls.cert_file and tls.key_file resolve against the config file's directory; logging.directory resolves against the current working directory. Absolute paths always work.

sections

SectionWhat it controls
[server]name, network, bind (default 0.0.0.0), port (default 6667).
[security]Line/param/nick length limits, flood guard (flood_max_msgs, flood_window), keepalive (ping_interval 120s, ping_timeout 300s), host_masking and its format, klines_file, default_user_modes (e.g. "iw"), max_connections, max_connections_per_ip, connect-flood auto-bans, reserved_nicks, ident and reverse-DNS lookups, DIE/RESTART passwords, oper_auto_join.
[tls]enabled (default false), port (default 6697), cert_file, key_file, request_client_cert (needed for SASL EXTERNAL). Runs alongside the plaintext listener, never instead of it.
[accounts]enabled (default false), store_file. Backs SASL, /REGISTER, /CERT and the a: extban.
[messages]motd file and max message length.
[logging]enabled, directory, level, debug (protocol trace), file, rotation (max_bytes, backup_count).
[[operators]]One table per /OPER login. See below.
[admin]Location and email reported by /ADMIN.
[[vhosts]]host plus allowed_hosts (ident@IP masks, never nicks) that /VHOST may activate.
[channels]restrict_creation, allowed_channels, default_modes (default "nt"), auto_join.
[dnsbl]enabled, zones, timeout, action ("kline" or "reject"), kline_duration, lookup_url.
[debug_channel]Oper-only channel (default #server-debug) that relays WARNING+ log lines as notices.
[links]Server-to-server linking: mode ("hub" or "leaf"), bind/port, tls, reconnect delays and [[links.peers]]. See ChanServ for a worked example.

tls

[tls]
enabled   = true
port      = 6697
cert_file = "tls/cert.pem"
key_file  = "tls/key.pem"

A self-signed certificate still encrypts the connection. Clients just need "only allow trusted certificates" unchecked. Channel mode +z then restricts a channel to clients connected this way.

operators

An [[operators]] entry is a /OPER login: name, hosts (ident@IP masks it may log in from) and exactly one of password_hash (scrypt, recommended) or a legacy plain password.

./bin/sekurircd --hash-password
# -> scrypt$16384$8$1$3f9c1a7b2e8d4f56...$91ab...   (example, truncated)
[[operators]]
name = "admin"
password_hash = "scrypt$16384$8$1$<salt-hex>$<digest-hex>"   # from the step above
hosts = ["*@*"]                                       # or restrict, e.g. ["*@203.0.113.42"]

Apply it with /REHASH from an already-opered client, sekurircd --rehash, or a restart, then confirm with /OPER admin <password>. Rotating a password is the same edit in place. Removing an entry does not deop clients that are already opered under it until they reconnect.

host cloaking

[security]
host_masking = true
host_masking_format = "{token}.users.{network}"
host_masking_token_bytes = 4

Real IPs and hostnames stay off the wire. An oper, or the user themselves, still sees the real address via WHOIS.

bans

KLINE, GLINE and ZLINE take an IP mask and an optional duration (1d, 12h, 30m; permanent if omitted). Set [security] klines_file to persist them across REHASH and restarts.
