web chat

The web chat is a small IRC client that runs in the browser and talks to the network over a secure WebSocket. No install and no account needed. It is one script, js/chat.js, with css/chat.css and a page that only has to contain <div id="sekurchat"></div>. The server address is a constant in the script, so there is no host field and no URL parameter that can point it somewhere else. Servers need a [websocket] listener with tls = true (see configuration).

using it

  • Connect: pick a nickname and up to 10 channels. A guest nickname is made up for you on every visit. Logging in to an account is optional: it uses SASL SCRAM-SHA-256 (the password never crosses the wire) and falls back to PLAIN only when the account has no SCRAM key yet. The password is kept in memory only, never stored.
  • Tabs: a status tab, one per channel, one per private chat. A tab turns red when something new arrives; × closes it (leaving the channel). A divider marks what you have not read, and with an account it follows you across devices (draft/read-marker).
  • History: the last 50 messages when you join a channel, and everything you missed after a dropped connection. Private history needs an account on both sides.
  • Nicks: click one to message them; right click (tap on a phone) for the menu: private message, mention, whois, client version, ping, ignore, and for channel ops give or remove op and voice, kick, ban, kick and ban.
  • Users: the list groups people by rank. A dimmed name is away (hover for the reason when it is known); a check mark means they are logged in to an account (hover for which).
  • Safety: links ask before leaving the site and show the real address, formatting codes are rendered without HTML, and you are marked away after 30 minutes without activity.
  • Ignore: /ignore nick hides their messages, notices and CTCPs. It is kept in your browser only.

commands

Type /help in the chat for a summary. Text starting with // is sent as a message starting with one /.

CommandPurpose
/join #chan [key]Join channels (# is added if you leave it out, commas allow several).
/part [#chan] [reason] /cycle /closeLeave, leave and rejoin (/hop), or close the open tab.
/msg nick text /query nick /notice target text /me actionMessages. /msg and /query open a private chat tab.
/topic [#chan] [text] /mode [+modes ...] /invite nick [#chan]In a channel tab the channel is the default, so /mode +m and /invite nick need no channel name.
/list [mask]Opens the channel list (also the list button): filter by name or topic, click a channel to join. Takes the server's LIST filters, for example /list >5.
/whois nick /who mask /away [text] /nick name /umode +modesWho is who, away status, nickname and user modes. /whois also shows idle time.
/ctcp nick version|time|pingAsk another client. The chat answers VERSION, PING, TIME, CLIENTINFO and SOURCE itself, at most four replies in ten seconds.
/op /deop /voice /devoice /halfop /dehalfop [#chan] nick [nick ...]Rank changes, up to 6 nicks at a time.
/kick [#chan] nick [reason] /ban [nick|mask] /unban nick|mask /kickban nick [reason]A nick becomes the mask *!*@host, the same as the nick menu's Ban. /ban alone lists the bans. /kb is short for /kickban.
/ns ... /cs ... /identify [account] passwordTalk to NickServ and ChanServ. Passwords are never shown in the log or kept for Up-arrow recall. No account yet: /msg NickServ REGISTER password.
/clear /quit [reason] /stopClear the open tab, leave the chat, cancel a paste that is still being sent.
/sound /joins /typing /notify [on|off]The settings below. With no argument a setting flips.
/quote COMMAND ... and anything elseSent to the server as typed, for example /motd or /help topic. Replies appear in the tab you typed in.

settings

The sliders button opens the settings. They are kept in your browser only.

SettingDefaultEffect
Joins, parts, quits, nick changesshownOff hides those lines, including the ones already on screen. Your own join, kicks and mode changes stay. A tab no longer turns red for hidden lines.
Typing indicatorsonShows who is typing under the message list, and lets others see when you are. Uses +typing on TAGMSG: sent at most every 3 seconds while you type, paused after 5 seconds, cleared when you send or empty the box. Not sent in the status, NickServ or ChanServ tabs.
SoundonA soft chime for private messages, notices, mentions and invites.
Desktop notificationsoffA pop-up for the same events, only while the tab is in the background. The browser asks for permission when you turn it on. Phone browsers mostly allow notifications only through a service worker or an installed web app, which this page does not use, so expect none there.

The Aa button cycles the text size and the people button shows or hides the user list.

pasting several lines

Pasting two or more lines opens a box first instead of sending anything. IRC has no paste box of its own: every line becomes a message that everyone in the channel has to scroll past, and many channels and their operators kick or ban for it.

Lines pastedWhat the box does
2 to 5Shows a preview and asks to send them as separate messages. Or paste them as one line when they fit in 400 characters.
6 to 50Warns that this floods the channel and suggests a paste site (dpaste.org, bpa.st, paste.debian.net) so you can share a link instead. You can still choose Send anyway; Cancel has the focus so Enter cannot send by accident.
more than 50Refuses, and points to a paste site.

Accepted lines go out one every 500 milliseconds, well inside the default flood guard of 20 lines per second, and always as plain messages: a pasted line that starts with / is text, never a command. /stop cancels what is left. Operators can change the limits, the pace and the suggested sites in js/chat.js (PASTE_WARN, PASTE_MAX, PASTE_GAP, PASTE_SITES). A channel with +f will still kick a flooder, whatever the client does.

capabilities it uses

CapabilityUsed for
saslAccount login while connecting (only when you fill in the account fields).
server-time message-tags echo-messageReal message times, typing indicators, and showing your own messages as the server saw them.
batch draft/chathistory draft/read-markerRecent history, catching up after a reconnect, and the read position.
multi-prefix userhost-in-namesCorrect ranks in the user list, and hosts for ban masks.
away-notify account-notify extended-join chghostThe away and logged-in markers, and keeping ban masks right after a host change. When you join, one WHO #channel %tcnfa (WHOX) fills in who is already away or logged in.

See IRCv3 & SASL for what the server offers. The chat does not request draft/multiline, so messages sent that way by other clients reach it as separate lines.
