SekurIRCd

A lightweight, secure IRC daemon written in C11. Native TLS, SASL, IRCv3, server linking and optional channel services. No runtime dependencies beyond OpenSSL.

sekurircd --quickstart

bash
$ git clone https://github.com/gcanosa/SekurIRCd.git && cd SekurIRCd
$ make                                   # bin/sekurircd, bin/chanserv
$ cp config/sekurircd.template.toml config/sekurircd.toml
$ ./bin/sekurircd --config config/sekurircd.toml

Needs a C11 compiler, make and OpenSSL 3 (or LibreSSL). TOML, JSON and hash-table libraries are vendored. Full steps in the install guide.

sekurircd --features

TLS built in

Opt-in TLS listener on 6697 alongside plaintext. Channel mode +z restricts a channel to TLS clients; +Z marks them in WHOIS.

Accounts & SASL

Self-service accounts with SASL PLAIN and EXTERNAL (TLS client-certificate login via /CERT), register via NickServ, /REGISTER or IRCv3 draft/account-registration, plus account-based ban masks.

IRCv3

away-notify, multi-prefix, extended-join, account-tag, server-time, echo-message, setname, chghost, MONITOR, WHOX and more.

Scrypt operators

Operator passwords stored as scrypt hashes, each login limited to an ident@host mask list. Generate with --hash-password.

Host cloaking

Hide real IPs and hostnames behind per-connection cloaks, with named vhosts and oper CHGHOST/SETHOST. Opers and the user still see the truth in WHOIS.

Protection bundle

An optional protection layer in one config file: DNSBL blacklists with per-zone reply rules, an active open-proxy scanner (HTTP, SOCKS4, SOCKS5), connection limits, connect-flood auto-bans, flood and spam protection, all reported live in your debug channel. Read more.

Server linking

Hub-and-leaf topology with scrypt-authenticated peers, optional TLS, network-wide KILL/WALLOPS/ban propagation and exponential-backoff reconnect.

ChanServ

A separate, optional process that links in and keeps channels registered: IDENTIFY, ACCESS, AKICK, GUARD, TOPICLOCK, SUCCESSOR, SET MLOCK.

Operator tooling

Snomask-style server notices, an oper-only debug channel, SAJOIN/SAPART/SAMODE overrides, and live REHASH without dropping anyone.

Daemon-friendly

--daemon, --stop, --rehash, PID files, rotating logs, and ready-made systemd user units. No root required.

Small & testable

Plain C11, -Wall -Wextra, an ASan+UBSan debug build and an assert-based self-check via make check.

Standard protocol

RFC 1459/2812 with IRCv3 negotiation. Works with WeeChat, irssi, HexChat, BitchX, The Lounge and Kiwi.

sekurircd --security

No eval, system or shell-out anywhere in the request path. Line length, parameter count and nick length are enforced, every client is isolated so one bad connection cannot take the daemon down, and slow ident/reverse-DNS lookups run on worker threads so they never block the event loop. Found something? Open an issue on GitHub.
